- Prove "unchanged" by diffing pixels: `git archive origin/main | tar -x` into the scratchpad, copy `node_modules` in, build and `next start` it on its own port, then canvas-diff full-page screenshots against the branch's build (sprint 2).
- Check a Tailwind v4 variant compiles by grepping the built CSS in `.next/static` with a fixed string and escaped class names (sprint 4).
- Focus rings: the shared `:focus-visible` rule lives in `@layer base` so utilities still win; where another element owns the ring use `focus-visible:outline-none`, since `outline-hidden` paints a ring in forced colors (sprint 4).
- Scroll-driven reveals: `entry N%` is a share of the element's height, so short sections snap; a fixed `entry 0% entry 64px` keeps one distance. Use `backwards`, not `both`. Don't fade sections (one that loads part-way in stays mid-fade and fails axe contrast), and never move a click target with a view timeline, which is a frame stale after a jump scroll (sprint 5).
- A view-timeline animation keeps its element on a composited layer for as long as the page can scroll back, which shifts antialiasing by 1 to 2 RGB: `will-change: contents` on the animated element keeps it painted with the page (sprint 5).
- `container-type` on `html` or `body` stops the body's background reaching the canvas; for exact full-bleed, wrap `main` in a `div.@container` and use `100cqw` (sprint 8).
- `next build` prints no first-load JS in Next 16: gzip what the browser fetched before `load`, minus `/_not-found` in the same build. A Server Component's inline SVG ships twice, as markup and in the RSC payload (sprints 8 and 10).
- Lint traps in WebGL code: biome takes `gl.useProgram()` for a React hook (call it through `.call`), and `invariants.spec.ts` rejects `rgb(` anywhere in `components/`, even in a function name (sprint 10).
- agent-browser `eval` calls share one global scope, so wrap each in an IIFE (sprint 4).
