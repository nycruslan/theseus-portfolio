# Mutants and scratch copies

Moved from MEMORY.md at sprint 85. Read before proving a check bites.

- Serve a long suite from a scratch copy's own build, never the worktree's `.next`: the stop hook runs `pnpm verify` (a `next build`) in the worktree whenever a turn ends, and a server on that `.next` then serves chunks that are gone (Forge's suite, sprint 55).
- To prove a check bites, run a mutant from a scratchpad copy of the app: copy every tracked top-level entry (`for f in $(git ls-files | cut -d/ -f1 | sort -u); do cp -a "$f" <copy>/; done`) plus node_modules. A hand-picked list rots: components/keel.tsx imports `.github/CODEOWNERS` and `CLAUDE.md` raw (sprint 55), and by sprint 85 the build also needed tsconfig.build.json, while pages/ and proxy.ts are product code a partial copy silently drops. Each copy on its own `PLAYWRIGHT_PORT`; about 40 s a mutant. Do it only when the check could pass on main without the change (sprints 13 and 21).
- Before a build exists, run new specs against a scratchpad mock of the contract's data rules (copied as for mutants): it caught a lookup by name that broke on the repeated "Earth Designs" and station figures read as plank numbers (.crew/sprint/23/).
- Before the build, force the hidden thing shown on main in a scratch spec (addStyleTag display:block) and run the new check: it proved W14's oracle passes where the key already shows, and told Forge what showing it costs (1024 x 768: links to 774) (.crew/sprint/45/).
- Two Playwright runs in one scratch tree share its test-results folder: a second run wipes it, and the first run's tests fail with ENOENT in context.close (four of the 23 reds on sprint 48's first mutant run). Give each concurrent run its own copy, or wait for the first to finish (.crew/sprint/48/).
- Worktrees share remote refs with every session, so `origin/<sprint branch>` moves when Atlas cherry-picks: take a mutant's "unedited" spec from a commit hash (`git show <hash>:e2e/x.spec.ts`), never the branch name; sprint 50's first mutant run carried the already-rewritten K6 this way.
- A bare mutant of the contract run on the whole suite found two reds a grep and Iris's fit missed: P17's /read row stopped wrapping at 390, and B1.4's two-word legend finder went null; find a list by one item's exact text, never by words its parent also holds (.crew/sprint/60/decisions.md, 1, 4, 8).
- A CSS-only mutant needs no rebuild: a scratch copy of the spec with `page.addStyleTag({ content: process.env.MUTANT })` after each load runs five mutants against one served build in under a minute; rebuild only for markup or script mutants (sprint 70, T30 and T31), or where the check reads the load itself (a fragment's landing).
