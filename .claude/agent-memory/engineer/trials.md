# The trials (/trials, sprint 63)

- The sweep (lib/trials-sweep.json, about 6 KB) is rewritten by `pnpm build && node .crew/sprint/63/trials-sweep.mjs` in about 40 s, and two runs on one build read identically, so a diff in its values is the page, never noise. The script lives in `.crew/sprint/63/`, not `scripts/`, because knip.json (the owner's) takes only `.crew/*.mjs` as script entries and reports any `scripts/*.mjs` as an unused file; it imports `lib/trials.ts` and `content/profile.ts` directly through Node's type stripping, which works only for modules with no imports of their own, so keep lib/trials.ts import-free. It stores tenths, rounded so the kind can't flip (a sinking −0.03 is −0.1, a near miss's 0.96 is 0.9), and run-length encodes each width's column, since the links' foot is constant or tracks the height for long runs (`.crew/sprint/63/`).
- In Playwright 1.64 on Node 22.23 (which has `module.registerHooks`), a module a spec loads by dynamic `import()` resolves its own imports natively, bypassing Playwright's resolver: CommonJS order `.js`, `.json`, `.node`, then `.ts`, so lib/trials-words.ts's bare `./trials-sweep` loaded lib/trials-sweep.json (or threw "missed cache") and T15 got `{}`. A static import from the spec resolves the same chain to the `.ts`; `./x.js` isn't found and `./x.ts` needs tsconfig's allowImportingTsExtensions (the owner's). So a lib module the runner loads must not import a name with a `.json` twin unless the spec imports it statically (`.crew/sprint/64/`).
- A segment's `opengraph-image` file is every child route's card unless the child sets its own `openGraph.images` or has its own file: `app/trials/opengraph-image.tsx` gave `/trials/frame` the 1440 × 900 card until `app/trials/frame/opengraph-image.tsx` re-exported the root's (gone since sprint 76 moved the frame to the Pages Router, which sets no card). proxy.ts's one-segment matcher also caught `/trials/opengraph-image` and sent it to the 404 until its lookahead excluded it (`.crew/sprint/64/`).
- Satori throws "Cannot read properties of undefined (reading 'toString')" on a style key whose value is `undefined` (`background: ground` with no ground): spread optional keys in, `...(ground ? { background: ground } : {})` (lib/trials-card-art.tsx, `.crew/sprint/64/`).
- A Server Component can't import a `.css` file as text: `?raw`, a Turbopack rule's `type: "text"` and `with { turbopackModuleType: "text" }` all hit Next 16.4's CSS client-reference transition ("css client asset is not css chunk placeable"). next.config.ts reads app/globals.css at build and passes its `@media` lines as env `STYLESHEET_MEDIA`, which lib/trials-fits.ts links the fits' lines from (`.crew/sprint/65/`).
- An SVG plot stretched unevenly (nested viewBox, `preserveAspectRatio="none"`) keeps a px mark only as a non-scaling stroke, and Chromium strokes a near-zero circle's outline wrongly under `vector-effect` (a hairline "O"): `stroke-dasharray: 0 1000` with round caps draws a true disc. A `<use>` copy (a halo, the ring's film) takes its own stroke only if the original's comes from a wrapping group, since a clone keeps the original's own declarations; and a band whose outline ran back over its own foot (joined across 480 to 767) filled wrongly until each run was its own subpath, so render a generated path alone before trusting it (components/trials-chart.tsx, `.crew/sprint/65/`).
- An inline box that is empty in one state and holds text in another (the found count's plank) can't sit by a baseline offset (`vertical-align: -4px`): empty, an inline-flex box's baseline is its foot, filled, its text's, so the two seat 6.5 px apart, the line grows at the first find and the chart under the pointer drops 4 px (T18). `vertical-align: middle` aligns by the midpoint, which no content moves (app/globals.css `.trials-found-plank`, `.crew/sprint/65/`).
- The sandboxed frame logs one "Blocked script execution" per executable script in its document (`noModule` included; the JSON-LD data block logs none), and Playwright's tracing (the config's `retain-on-failure`) injects one more into it, so a console check on the trials passes only with `trace: "off"`. agent-browser's `console` shows no child frame's log entries: read them with Playwright's page `console` event in Chrome (`/usr/bin/google-chrome`) (`.crew/sprint/76/`).
- An SVG `<text>`'s `x` and `y` aren't CSS properties in Chromium (a rect's and an svg's are), so a chart label that a media or container query must move takes its offset as `translate`, and only there: on a text placed at a fractional px, a translate dropped the lower row of 1366 × 595's 1 px underline at 1x, so a fixed offset stays in the `x` attribute. A label's film pad sized in em (`max(28px, 2.125em + 4px)`) keeps a nearby pin's dot off its digits at a large font, where a px pad let it print "−6,2". The chart switches a label's seat by its own width (456 × 465's in sprint 78, the gap's pocket since 79) through `container: trials-chart / inline-size` on the figure, as `.trials-figure` beside it already was, with a calc(px + rem) threshold: two points' distance is a fixed share of the plot (136/1616 for the gap to 456 × 465) and the label's width is rem. 0 of 526 boxes moved at 16 px outside the switch (`.crew/sprint/78/`).
- T38 counts a sounding's focus ring even while it's hidden (34 × 21 about its pad, its top 2 px above the gap's point from 64rem), so the gap's label had to clear it to 1195 wide, not just the pad to 1151. A seat switch set at its exact threshold leaves about 0 px at the switch (0.06 in the shell, 0.68 in Chrome 153), so sweep it a pixel at a time in both browsers. The gap's pad also hid pins 360×560 and 375×548 at every width, until sprint 79 seated the label on its dot (`.crew/sprint/78/`).
- The crew's dots show over the ring's film because the top svg draws them again, `<use href="#trials-pin-dots">` halo then ink between the film and the ring's dot, masked by a `maskUnits="userSpaceOnUse"` mask of a white rect and a `<use>` of the ring itself (7 px #000 stroke) as the hole: the hole follows the controller's cx and cy with no script, and a ring on a pin looks as before. The dots need a group of their own (H10's bar stays out, under the film), the mask `forced-color-adjust: none`, and the copies their own forced-colours strokes. The gap's label moves to its pocket as a group by `transform-box: view-box; translate: <share of the plot>`, since Chromium ignores CSS x and y on a nested svg (`.crew/sprint/79/seat.md`).
- A whole-px y `translate` on the soundings' numbers (the lift that keeps them in an em pad at a large font) drew the same 1x underline rows as the offset in the y attribute and as a translate on a wrapping `<g>`, at 16 to 28 px and 390, 1024 and 1440, so it stays on the text; 0 px at 16 left every number's rows as main's (`.crew/sprint/79/`).
