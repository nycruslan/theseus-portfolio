# The Log's lessons (from MEMORY.md, sprint 53)

- A rule that waits on a record written after the merge (merge.json) meets its own PR's CI with the newest sprint unrecorded: walk each order rule and "newest" sample through that state before writing (Undated last would have put 32 under revision 1; B5.15's newest became the newest with a record) (.crew/sprint/32/decisions.md, 9).
- Grouping a table's tbody adds header rows, so every spec's `tbody tr` selector counts them: the Log's revision rows are `tbody tr:has(> th[scope="row"])`, in log.ts, log-entry.spec.ts and sheet.spec.ts (.crew/sprint/32/).
- Below 768 px on the Log the bar's Read as page and control slot are hidden and one row (`main > [data-foot]`, `.log-head`'s next element in the DOM; since Ya, sprint 53, set under the h1 and above the drawings, Iris's addendum) holds Read as page then the control, so the bar's target list is the header's shown targets then the row's, the same list at every width; Tab from Contact goes Read as page, then Off with WebGL refused (.crew/sprint/31/, the merge with #83).
- B5.6's hand-written plank anchors (sprints 1, 13, 24 in e2e/log-record.spec.ts) gain "Sprint N has since replaced it." whenever a merge retakes their seat, 22 merged retros on (36 took 13's 6.1, 46 took 24's 5.1): at each close, run `seatHolders` from lib/lines-plan.ts on the merged list and grep e2e/ for the next seat's holders before CI finds it (sprint 46).
- Every step's server HTML is read in seconds: `request.get(url)`, then `page.setContent(html)` in a scripts-off context with `page.route('**/*', abort)`, and the same in-page reader as a real page; it answers structure and words, never paint, so a check needing paint loads the contract's sample pages (e2e/log-yard.spec.ts serverYards: 52 pages, Y1 6 s, sprint 53).
- The yard's oracle is e2e/retros.ts (STEPS, THESEUS_AT, GHOST_AT, COUNT_AT, QUESTION_STEP, from the contract's rule), its words YARD_WORDS in e2e/log.ts (Iris's, one line each), and `ghostOn(url)` in e2e/ghost.ts the ghost a page draws: a check on a record's ghost reads ghostOn, never GHOST, since a step's ghost has gaps before its 22nd merge (B5.18, B5.19 since sprint 53).
- A contract's "measured room" can miss a kept first-screen clause at another size: Ya's measured 390 x 844 and 1440 x 900, but B5.25 holds Full, Calm and Off inside 320 x 568, with 29 px of room on main, and the bare mutant found it; list every kept clause's viewport (B5.25 320 x 568, B5.18's fits, B5.1) before the placement call (sprint 53).
