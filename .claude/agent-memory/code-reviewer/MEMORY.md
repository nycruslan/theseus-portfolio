- Ports: probe with `curl --noproxy '*' localhost:<p>` first; other agents hold ports. Stop your own `next start` by PID (the guard refuses pkill).
- The worktree guard refuses commands that pass `$VAR` paths to node or mix `cd` with loops; write absolute paths literally.
- Grep-based "no X" e2e checks: look for the escape hatch. In sprint 2, Tailwind's arbitrary variant `[@media(prefers-color-scheme:dark)]:` compiled to a second dark rule that the `dark:` regex missed. Test a candidate by compiling it with `import { compile } from "tailwindcss"` plus `c.build([cls])`.
- The app has no `app/not-found.tsx`, so Next's fallback inlines `body{#000/#fff}` and ignores the tokens. Check `/nope` whenever theming or metadata changes.
- Declaring `color-scheme` makes Lightning CSS add `--lightningcss-light/dark` to the compiled `:root` and dark block. That's harmless, and source-level checks don't see it.
- Render a component branch the content can't reach (e.g. a project with no `href`): transpile the `.tsx` with `typescript`'s `transpileModule` (jsx react-jsx, CommonJS), rewrite `require("react/jsx-runtime")` to its absolute path, render with `react-dom/server`, then put the markup into the running page to see it under the real CSS. Write the script with Write first; the guard refuses a script that is written and run in the same command.
- Stacked elements that share a seam via `-mt-px` need a `z-index` on every state that paints the edge (hover and focus), or the next sibling paints over its bottom pixel row. Computed-style checks miss this. Read the pixels instead: no PIL here, so draw the PNG to a canvas in Chromium and sample a column.
- Tailwind v4 arbitrary `calc(--spacing(8)-1px)` compiles with spaces around the operator, so it's valid. Check by grepping `.next/static/chunks/*.css`.
- Scope check locally: import `scopeNotes` from `.studio/scope.mjs` and feed it `git diff base...head` per file as GitHub's files list ({filename, status, patch from the first `@@`}). It reproduces CI's notes; the PR-level diff is what counts, so lines dropped from a test file the same PR added never count as removals.
- A spec that needs `origin/main` (CI has a one-commit checkout) ends in `test.skip(`, which scope.mjs rejects as weakening. Owner-path guards (content/ etc.) belong to scope.mjs/gate.mjs, not e2e.
- Tailwind v4 `outline-hidden` is `outline-style:none` plus a 2 px transparent outline under `@media (forced-colors: active)`, which forced colors paints. Where another element owns the ring, the link needs `outline-none`. To compile in node: `mod = await import(require.resolve("tailwindcss"))` is CJS, so use `mod.compile ?? mod.default.compile`, with `loadStylesheet` resolving `tailwindcss/index.css`. Source order inside one variant shows who wins (e.g. `focus:not-sr-only` comes before `focus:fixed`/`px-*`).
- Blanket `[tabindex="-1"]:focus{outline:none}` resets: ask for them to be scoped to the skip-link target. ARIA menu, listbox and roving-tabindex items carry `tabindex="-1"` and get focused from script.
- e2e helpers like `tabUntil(selector)`, where the selector matches every card's link, always stop at the first card. Per-card loops built on them only hold while one item qualifies; look for this whenever a check loops over `withLink`.
