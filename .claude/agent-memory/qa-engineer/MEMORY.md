- Iterating fast: serve a build yourself and run `PLAYWRIGHT_BASE_URL=http://localhost:<port> pnpm exec playwright test e2e/<file>`, which skips the config's build; final runs use `PLAYWRIGHT_PORT=<free> pnpm test:e2e`. `@playwright/test` is the importable package, so scratch scripts require it by absolute path.
- A redesign meets the live specs in clusters, and almost every spec loads `/` only. For B1, list each spec as keep, rewrite with the same assertions, or retire for the owner to approve, and give a new route its own axe, overflow, keyboard and 24 px target checks (sprints 12 and 15).
- Specs that hard-code the page's sections (`reveal.spec.ts`) break on any new one: check for hard-coded lists before a contract says nothing else changes (sprint 6).
- With scripts off, `page.evaluate` still works but `requestAnimationFrame` and `setTimeout` inside it never fire, and `locator.boundingBox()` and `addStyleTag` hang: poll from the test and measure with `page.evaluate` (sprints 5 and 9).
- Next puts viewport and meta elements and the 404 boundary's CSS in `self.__next_f` flight scripts, so a whole-HTML "no script mentions X" check hits framework text (sprint 2).
- Reading styles right after `emulateMedia` can catch a transition mid-fade: set the scheme, then `goto`. Await `document.getAnimations()` filtered to `a.timeline === document.timeline`, since view-timeline animations never finish (sprints 3 and 5).
- CI's headless Chromium draws WebGL in SwiftShader and refuses `failIfMajorPerformanceCaveat`, so specs need an init script; read WebGL pixels from screenshots, never `readPixels`. The harness (`e2e/webgl.ts`, `e2e/pixels.ts`, `openRun` ordering the init scripts with the recorder last) retired with the hero in sprint 22: take it from git history for B3's 3D (sprints 9, 10 and 22).
- First-load JS: sum the script responses the browser fetched and subtract `/_not-found` in the same build. Next 16 prints no route sizes; raw bytes are in `.next/diagnostics/route-bundle-stats.json` (sprint 9).
- Chrome never counts a `data:` URL or a flat, low-entropy image as an LCP candidate, so an "LCP is not an image" check bites only on a busy image served from a URL (sprint 8).
- `getBoundingClientRect` on an SVG `g` or `path` is its fill geometry; read painted colours through a canvas with two different fallback fill styles to catch an unparsable `color-mix` (sprint 8).
- biome bans `waitForTimeout` and `networkidle` (wait with `page.evaluate(setTimeout)` or a Node timer), and an empty `({}, testInfo)` pattern is an error (sprints 3 and 8).
- An inline link's box is its glyph box (21 px for a 16 px font), not the line box, so target-size checks fail on bare inline links (sprint 4).
- In forced colors Chromium paints a background-only pseudo-element dot opaque Canvas, equal to the page's background: a check that it shows asserts it differs from `getComputedStyle(document.body).backgroundColor` (sprints 20 and 21).
- A data-driven page's oracle reads the files the page reads (sorted, counted), never a literal count, so new sprints don't break it (sprint 12).
- To prove a check bites, run a mutant from a scratchpad copy of the app (`cp -a app components content e2e lib .crew .claude package.json next.config.ts tsconfig.json playwright.config.ts pnpm-workspace.yaml node_modules`), each copy on its own `PLAYWRIGHT_PORT`; about 40 s a mutant. Do it only when the check could pass on main without the change (sprints 13 and 21).
- An sr-only skip link is a 1 px box that `isVisible()` calls visible, so `locator.hover()` on it retries "outside of the viewport" until the test times out: skip `a[href="#main"]` in hover loops and reach its focused state by Tab (sprint 22).
- The sheet's oracle is `e2e/retros.ts` (valid retros, planks seated by ORDER, the revision cells); specs import it rather than each re-reading the retros, and the page's reader is loaded at run time so a missing field fails one test, not the file (sprint 22).
- An overlap check (a sticky bar over content) must put the content under the very point it hit-tests, and assert that as a precondition: a card set 24 px under the bar's bottom never reached the links' centres, so the first draft passed on the bug (.crew/sprint/22/fix-round-2.md).
- Where a stolen click would follow an external link, `page.route` aborts every other origin, so the check fails on its landing assertion instead of leaving the site; click with `page.mouse` there, since `locator.click()` waits out an intercepting element until timeout (.crew/sprint/22/fix-round-2.md).
- An overlap check under a sticky bar appends a 100vh spacer to the body first: on a short page the last sections can never scroll under the bar, and without it three of B2.3's six targets were silently skipped (.crew/sprint/23/).
- Before a build exists, run new specs against a scratchpad mock of the contract's data rules (copied as for mutants): it caught a lookup by name that broke on the repeated "Earth Designs" and station figures read as plank numbers (.crew/sprint/23/).
- A print contrast floor composites each text's own painted backgrounds over white: an inverted box (Detail A's gateway, print-color-adjust exact) prints light text on its ink fill (.crew/sprint/23/notes-iris.md).
