- Iterating fast: serve a build yourself and run `PLAYWRIGHT_BASE_URL=http://localhost:<port> pnpm exec playwright test e2e/<file>` (skips the config's build); final runs use `PLAYWRIGHT_PORT=<free> pnpm test:e2e`.
- `@playwright/test` is the importable package in this repo (no bare `playwright`). No flaky checks seen in sprints 1 and 2.
- Facts learned in sprint 2: Tailwind preflight makes a bare `<input>` background transparent, use `background-color: revert` or `Canvas` to observe `color-scheme`. `page.evaluate` works with `javaScriptEnabled: false` (page scripts are off; `self.__next_f` is undefined proves it). Next puts viewport/meta elements and the 404 boundary CSS in `self.__next_f.push(...)` flight scripts, so a whole-HTML "no script mentions X" check fails on framework text.
- Chrome's default focus ring (`outline: auto`) paints white in dark and shows on the hull; computed `outline-color` reads `rgb(16,16,16)` anyway, so don't judge it from that (sprint 2).
