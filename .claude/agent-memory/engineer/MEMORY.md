- Tailwind v4's auto-detection scans `.crew` and `.claude` and ships their class names, so `app/globals.css` uses `@import "tailwindcss" source(none);` with `@source "../app"; @source "../components";` (CSS fell from 19,946 to 10,298 bytes). Keep new source folders listed there (`.crew/sprint/1/review-lens.md`).
- Build-time file reads under `cacheComponents`: a sync `node:fs` read in a Server Component prerenders fine, but a run-time `readdirSync(dir)` makes Turbopack trace the whole project unless its argument carries `/* turbopackIgnore: true */` (`.crew/sprint/13/`).
- A page that sets its own `openGraph` or `twitter` metadata loses the root `opengraph-image`: a segment `app/<route>/opengraph-image.tsx` that re-exports the root's `alt`, `size`, `contentType` and `default` restores one `og:image` and one `twitter:image` (`.crew/sprint/18/`).
- agent-browser takes `set viewport <w> <h>` and `set media dark|light` (the bare forms fail silently), ignores a screenshot's path and writes to `~/.agent-browser/tmp/screenshots/`; check `eval innerWidth` before a screenshot (`.crew/sprint/13/`).
- Forced colors drops `background-color` but not `border` or `outline`, so a drawn dot needs `forced-colors:before:bg-[CanvasText]`. Playwright's `forcedColors: "active"` shows it; agent-browser has no such switch (`.crew/sprint/20/brief.md`).
- `overflow-x-clip` clips sideways and leaves `overflow-y` visible, unlike `overflow-x-hidden`, which forces y to `auto` (`.crew/sprint/20/brief.md`).
- biome's `noArrayIndexKey` also flags a key built from the `.map` index: key duplicates by an occurrence count instead (`components/sprint-entry.tsx`, `.crew/sprint/14/`).
- JSX text trims a leading space, so text that starts with a non-breaking space and a space is a template literal (`.crew/sprint/14/`).
