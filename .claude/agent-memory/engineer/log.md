# The Log (/log and /log/n): its layout, its drawings and its steps

Moved here from MEMORY.md in sprint 53, when it neared its 25 KB load limit. One line each, with
the reason.

- The yard (sprint 53): `/log/n` draws the Theseus (`[data-theseus]`, never `[data-plan]` or `[data-ghost]`) right before the ghost, since the 3D chunk reads `[data-model]`'s `previousElementSibling` and the hollowing CSS keys on `:has(+ [data-model])`; a step changes planks, never places (Iris's flip-book rule). From 1024 the header, foot row and record are one column, `.log-side` (`display: contents` below 1024, so flex `order` still reaches each child and the Foot stays `.log-head`'s next element), so neither the drawings nor the record move; rows `auto 1fr` put a taller header's slack under the ghost, where auto rows open a gap between the ships; and the model's layer clips to its grid area, so `.log-ghost + [data-model]` spans both drawings' rows, `1 / 1 / 3 / -1`, or the canvas vanishes (`.crew/sprint/53/placement.md`).
- Below 768 the Foot (Read as page and the motion control) sits under the h1 at the drawings' head, `.log-side > .foot { order: 2; margin: 12px 0 0; padding: 0 }`, as `/` hangs it from the bar: at the header's end, after the count line, it left Full, Calm and Off below a 320 x 568 first screen once the Theseus stood above the ghost (B5.25), and B5.1 wants every `.log-head` line above it. Start again follows it in the DOM, outside `.log-head`, or Tab reaches it before Read as page (`.crew/sprint/53/placement.md`, the addendum; before that, `.crew/sprint/31/`, `.crew/sprint/33/notes-iris.md`, section 5).
- A text-decoration on an inline-flex link reaches every flex item, so an `inline-block` arrow as the link's direct child is still underlined; give the link's words one inner span with the arrow inside it, where an inline-block is an atomic inline the underline skips (the record's step links, `.crew/sprint/53/`).
- A page whose DOM order differs from its visual order (the Log's drawings follow the header and record but CSS `order` sets them above the caption) shifts layout whenever the browser paints HTML cut before the late element; reproduce it with a proxy that sends the HTML in two pieces at a marker (it gave B5.25's 0.06992813107324625 to the digit), and hold the first paint with `<link rel="expect" href="#<next element's id>" blocking="render">`, which React 19 hoists into the head from any component (`.crew/sprint/33/`).
- A block whose rule must span its column while its text keeps a measure: `max-width: none; padding-right: max(0px, 100% - 66ch)` keeps the content box at exactly 66ch, and the percentage resolves against the flex container even through a `display: contents` parent; `.log-head p`'s 66ch (0,1,1) outranks `.log-lines` (0,1,0), hence `.log-head .log-lines` (`.crew/sprint/33/`, Iris's rider on #82).
- Next 16.4 patches `history.replaceState`: data without `__NA` (pass `null`) has Next copy its own entry state in and dispatch a restore, so `usePathname` and its router follow the URL with nothing fetched on an unchanged tree; data carrying `__NA` (`history.state` itself) bypasses the patch, and the router's stale URL is written back on its next commit. The yard's press replaces the URL with `null` (`lib/model/yard.ts`, `.crew/sprint/55/`).
- A group header row (`th[scope=rowgroup]`) inside `.rev`'s folded grid lands in the 36 px number column unless its `tr` and `th` are `display: block`; and a `tbody:first-of-type` rule outranks the fold's own padding, so scope it to the widths it is for (`.crew/sprint/32/notes-iris.md`, Iris's early look).
- A step's words that move an element the page keeps, past Chrome's 500 ms input window, are a layout shift (the question at 23 moved `.record` and `.log-lines`: 0.0253 at 390, 0.0091 at 1440), and a held key or a riffle's stop has no input then; Chromium never counts a newly inserted element, so the yard swaps `.log-head`'s children and replaces `.record` itself (and `.log-revs` when it moves in view), measured 0 in every case. Any new swapped region comes in as new elements, never as a kept element's new children (`lib/model/yard.ts`, `.crew/sprint/56/`).
- A press stepped at `pointerdown` (the yard's mouse press and hold) must let the press's own mousedown focus the link before the words replace it: replaced in a microtask of the pointerdown, focus falls to `main`, and `preventDefault` plus a script `focus()` shows the ring, since nothing had mouse focus before (Iris's review). Swap a task later (a `MessageChannel` message, which Playwright's paused clock doesn't hold), then move focus to the replacement by script: no ring. The click that ends the press does nothing by a flag set at that pointerdown and `event.detail > 0` (a keyboard Enter's click has detail 0); don't clear it on keydown, or Escape mid-hold lets the ending click step (`.crew/sprint/56/`).
