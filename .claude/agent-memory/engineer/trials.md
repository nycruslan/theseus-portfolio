# The trials (/trials, sprint 63)

- The sweep (lib/trials-sweep.json, about 6 KB) is rewritten by `pnpm build && node .crew/sprint/63/trials-sweep.mjs` in about 40 s, and two runs on one build read identically, so a diff in its values is the page, never noise. The script lives in `.crew/sprint/63/`, not `scripts/`, because knip.json (the owner's) takes only `.crew/*.mjs` as script entries and reports any `scripts/*.mjs` as an unused file; it imports `lib/trials.ts` and `content/profile.ts` directly through Node's type stripping, which works only for modules with no imports of their own, so keep lib/trials.ts import-free. It stores tenths, rounded so the kind can't flip (a sinking −0.03 is −0.1, a near miss's 0.96 is 0.9), and run-length encodes each width's column, since the links' foot is constant or tracks the height for long runs (`.crew/sprint/63/`).
- In Playwright 1.64 on Node 22.23 (which has `module.registerHooks`), a module a spec loads by dynamic `import()` resolves its own imports natively, bypassing Playwright's resolver: CommonJS order `.js`, `.json`, `.node`, then `.ts`, so lib/trials-words.ts's bare `./trials-sweep` loaded lib/trials-sweep.json (or threw "missed cache") and T15 got `{}`. A static import from the spec resolves the same chain to the `.ts`; `./x.js` isn't found and `./x.ts` needs tsconfig's allowImportingTsExtensions (the owner's). So a lib module the runner loads must not import a name with a `.json` twin unless the spec imports it statically (`.crew/sprint/64/`).
- A segment's `opengraph-image` file is every child route's card unless the child sets its own `openGraph.images` or has its own file: `app/trials/opengraph-image.tsx` gave `/trials/frame` the 1440 × 900 card until `app/trials/frame/opengraph-image.tsx` re-exported the root's. proxy.ts's one-segment matcher also caught `/trials/opengraph-image` and sent it to the 404 until its lookahead excluded it (`.crew/sprint/64/`).
- Satori throws "Cannot read properties of undefined (reading 'toString')" on a style key whose value is `undefined` (`background: ground` with no ground): spread optional keys in, `...(ground ? { background: ground } : {})` (lib/trials-card-art.tsx, `.crew/sprint/64/`).
- A Server Component can't import a `.css` file as text: `?raw`, a Turbopack rule's `type: "text"` and `with { turbopackModuleType: "text" }` all hit Next 16.4's CSS client-reference transition ("css client asset is not css chunk placeable"). next.config.ts reads app/globals.css at build and passes its `@media` lines as env `STYLESHEET_MEDIA`, which lib/trials-fits.ts links the fits' lines from (`.crew/sprint/65/`).
- An SVG plot stretched unevenly (nested viewBox, `preserveAspectRatio="none"`) keeps a px mark only as a non-scaling stroke, and Chromium strokes a near-zero circle's outline wrongly under `vector-effect` (a hairline "O"): `stroke-dasharray: 0 1000` with round caps draws a true disc. A `<use>` copy (a halo, the ring's film) takes its own stroke only if the original's comes from a wrapping group, since a clone keeps the original's own declarations; and a band whose outline ran back over its own foot (joined across 480 to 767) filled wrongly until each run was its own subpath, so render a generated path alone before trusting it (components/trials-chart.tsx, `.crew/sprint/65/`).
- An inline box that is empty in one state and holds text in another (the found count's plank) can't sit by a baseline offset (`vertical-align: -4px`): empty, an inline-flex box's baseline is its foot, filled, its text's, so the two seat 6.5 px apart, the line grows at the first find and the chart under the pointer drops 4 px (T18). `vertical-align: middle` aligns by the midpoint, which no content moves (app/globals.css `.trials-found-plank`, `.crew/sprint/65/`).
