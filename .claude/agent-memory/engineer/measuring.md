# Measuring: renderers, default fonts, builds side by side and production

Moved here from MEMORY.md in sprint 67, when it neared its 25 KB load limit. One line each, with
the reason.

- agent-browser 0.39.0's Chrome and Playwright's Chromium set the same text at different widths, because Playwright's Chromium sets glyphs at whole-pixel widths (a line's width comes back as an integer) and agent-browser's Chrome at fractional ones, as real Mac and Windows Chrome do: on `/` at 390 the bio is 5 lines in one and 4 in the other (23 px), and at 1440 the particulars' Reach fits one line in agent-browser but wraps in Playwright (17 px). Measure pinned geometry in Playwright's Chromium, as the checks do (a scratch `chromium.launch()` script importing `@playwright/test` by the worktree's absolute `node_modules` path, since ESM resolves from the script's folder), use agent-browser for looking, and where a fit hangs on a wrap measure it in both: at 1280 the bio's three lines held by 0.86 px in Playwright and took four in Chrome. The two renderers wrap different lines, so a reserve must cover the worst of each: at 390 Chrome sets the bio on 5 lines and Leads on 1, while Playwright sets the bio on 4 and Leads on 2 (below 402). CI installs the headless shell (`--only-shell`; Chromium 156 for Playwright 1.64), and Chrome 153 is `/usr/bin/google-chrome` through `chromium.launch({ executablePath })` (`.crew/sprint/39/`, `.crew/sprint/43/placement.md`, the amendment; `.crew/sprint/44/`).
- To prove a change moves nothing or keeps output byte-identical, serve the before and after builds side by side from scratch copies (MEMORY.md's review server), `cmp` each card PNG (next/og drew byte-identical cards across builds, the on-demand 320 × 568 one too), diff the HTML with `/_next/static/…` paths and the build id normalised, and dump every element's `getBoundingClientRect` by nth-child path at each width: 0 of 1042 /log boxes moved at 320, 390, 1024 and 1440 (`.crew/sprint/67/`).
- Production read over the proxy painted /log at 390 once in the fallback font (`display: optional`), every bar link 1 to 12 px off, and a second load matched: re-measure production before calling a move, and expect its record rows and lines figure to differ from a sprint branch that carries newer merge records (`.crew/sprint/67/`).
- /evals draws its categories only from the Blob report, which a local build can't read, so a local /evals has no h2 under its title: lay production's `header.doc-head` and `section.sched` outerHTML into both builds' page for a box diff or an edge read, and check a CSS change on production's real page by `addStyleTag` with the new rules over its own stylesheet (equal specificity, later wins) (`.crew/sprint/69/`).
- A fresh `next start` can answer its first request of `/` before the page is drawn (a control diff of one build against itself read 691 of 698 boxes changed on the first `/`): fetch every page from both servers before a box diff, and run that control first (`.crew/sprint/69/`).
- Neither local browser hyphenates: `hyphens: auto` with `lang="en"` left "Groundedness" whole in a 90 px box in Playwright's headless shell (156) and /usr/bin/google-chrome (153), which have no hyphenation dictionaries here, so a fix that needs a hyphen can't be checked locally and would break differently on Mac and Android. `overflow-wrap: break-word` breaks without one and, unlike `anywhere`, leaves min-content alone: as a backstop on the heads it moved 0 of 31,056 boxes at 16 px (`.crew/sprint/69/`).
- Playwright's element and full-page screenshots fit the page by overriding the device metrics, which drops a CDP `Page.setFontSizes` default font: the root read 28 px before the shot and 16 after, and the picture showed the 16 px page. Shoot a viewport clip in a window tall enough to hold the element (`.crew/sprint/70/`).
- The yard's hint (`.record-hint`) shows only while the model plays, so checks and sweeps that refuse WebGL never see it: with WebGL on, on the newest step at 320 and 390 with a 24 or 28 px default font, its fixed 14 px line wrapped and printed over the hand-off link until sprint 73. Sweep a large font with WebGL on as well as refused, or show it by hand (`data-yard` on `[data-model]`, as H3 and T34 do) and read its text's `Range.getClientRects()` against every other word's (`.crew/sprint/70/`, `.crew/sprint/73/`).
- A review server that outlives rebuilds: copy `.next` (without `dev/`), `package.json`, `next.config.ts` and `app/globals.css` (the config reads it at start, for the trials' media lines, and exits without it) to the scratchpad, symlink `node_modules` and `.crew` (`/` and `/crew` scan `.crew/sprint` per request and answer 500 without it; prerendered /log pages serve regardless), and run `next start` from that folder; Turbopack's build refuses a symlinked node_modules, start doesn't. `PLAYWRIGHT_BASE_URL=http://localhost:<port>` then runs specs against that exact build without rebuilding `.next` (`.crew/sprint/23/`, `.crew/sprint/25/`, `.crew/sprint/72/`).
- A teammate's spec on your build without touching `e2e/`: a scratch folder holding a copy of `e2e/`, `playwright.config.ts`, `package.json` and `tsconfig.json`, their spec laid over it from `git show origin/<branch>:e2e/<file>`, and symlinks to `node_modules` and the folders specs import or read (`lib`, `content`, `components`, `app`, `public`, `.crew`); run Playwright there with `PLAYWRIGHT_BASE_URL` at each review server, base and change, to see it red then green (T33 and T32, `.crew/sprint/72/`).
