- A reader's default font is CDP's `Page.setFontSizes({ fontSizes: { standard: N } })` before `goto` (Chrome's Large 20, Very large 24; `setDefaultFont` in e2e/reader-font.ts); rem and a media query's rem follow it, so assert the root's computed font-size took. One overflow hides the next: at 320 x 568, 24 px, the bar's Contact (373) masked the sheet's drawing figures (341) and the trials' Freeboard (340), found only by hiding the bar with injected CSS and re-measuring scrollWidth, so sweep every route that way before calling a fix whole (T25, T27, .crew/sprint/68/).
- A Range's rects aren't clipped by overflow, so "words inside the page" already fails an overflow-hidden fix; the clipping clause is what catches a heading cut inside its own box while its words still fit the page (an `h1, h2 { overflow-x: hidden }` mutant cut document-ai's h1 at 304, words to 315, at 320 and 24 px) (.crew/sprint/69/).
- A media query's rem is the reader's default font, so the bar's md/lg breakpoints (48rem, 64rem) move with it: at 1024 x 24 and 1024/1180 x 28 the page lays out as a phone (Read as page hidden, the control in the foot), and lg needs 1536 at 24 px. A large-font check reads `matchMedia("(width >= 48rem)")` to know which layout it's in, never the px width (T32, .crew/sprint/71/).
- An `overflow: hidden` mutant on a fixed-width group clips its first button at 16 px too (the group's buttons already overflow 142 px there, unseen), so it reds every font; the clipper (box cut by an overflow ancestor, words by the element's own) plus scrollWidth over clientWidth caught it (T32, .crew/sprint/71/). The same mutant on `.record-steps` clips the next step from 20 px (1280 x 20) and zeroes the page's sideways scroll, so only the clipper and the link's own edges keep it red (T33, .crew/sprint/72/).
- Count a link's lines from its text nodes by vertical overlap, never by distinct rect tops over a Range of the whole link: the step links' `.step-arrow` is an inline-block whose glyph box sits a few px off the words', so "Seat sprint n's plank →" read two lines at every size; skip `.sr-only` text too, whose 1 px box's words run past it (T33, e2e/large-font-steps.spec.ts, .crew/sprint/72/).
